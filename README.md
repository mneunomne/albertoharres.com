# alberto harres

Source for [albertoharres.com](https://albertoharres.com), built with Nuxt 2 and deployed on Netlify.

## Install

```bash
npm install
```

## Run

```bash
npm run dev        # dev server at http://localhost:3000
```

## Build

```bash
npm run generate   # static site in dist/ (what Netlify deploys)
npm run build      # production build for `npm start`
npm start          # serve the production build
```
